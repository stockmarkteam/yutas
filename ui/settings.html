yutas 設定

確認中

アクセシビリティの許可が必要です

キー入力の検知と、清書結果の貼り付けに使います。システム設定の一覧で yutas をオンにすると、すぐ動き始めます。

一覧でオンなのに動かないときは、ビルドし直す前の許可が残っています。

既定の口調

清書するときの文体です。下のボタンで定型を入れてから、自由に書き換えられます。

アプリ別の口調

入力先のアプリによって口調を切り替えます。該当するアプリがなければ既定の口調を使います。

追加の指示

口調以外で常に守らせたいことを書きます。例:「句点の後に改行しない」「英単語の前後に半角スペースを入れる」

辞書

左の読みや略記を打つと、必ず右の表記になります。固有名詞や社内用語の表記固定にも、短い略記の展開にも使えます。例:「ゆたす → yutas」「おつ → お疲れ様です」

読み・略記表記
まだ単語がありません。

清書に使うAI

Claude は速くて高精度です。入力した文章は、社内の Claude apps gateway を通して処理されます(Anthropic の API には直接つなぎません)。ローカルLLM はこの Mac の中だけで処理します。

接続先は ax.stockmark.co.jp、モデルは Claude Haiku 5.5(国内リージョン)に固定です。

Ollama(既定のURL)、LM Studio(http://localhost:1234/v1)、llama.cpp などの OpenAI 互換サーバーに接続します。サーバーは別途起動しておいてください。
